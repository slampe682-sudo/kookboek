beschrijving: Romige havermout die je 's avonds klaarzet en 's ochtends koud uit de koelkast pakt. Ideaal voor drukke ochtenden.
ingredienten:
  - { hoeveelheid: 100, eenheid: g, naam: havervlokken }
  - { hoeveelheid: 200, eenheid: ml, naam: melk (of plantaardige melk) }
  - { hoeveelheid: 150, eenheid: g, naam: Griekse yoghurt }
  - { hoeveelheid: 2, eenheid: el, naam: chiazaad }
  - { hoeveelheid: 1, eenheid: el, naam: honing of ahornsiroop }
  - { hoeveelheid: 0.5, eenheid: tl, naam: kaneel }
  - { hoeveelheid: 150, eenheid: g, naam: "vers fruit (bijv. blauwe bessen, aardbeien, banaan)" }
  - { hoeveelheid: 2, eenheid: el, naam: "noten of granola, om te serveren" }
  - { naam: snufje zout }
tip: Maak 's zondags meteen 4 potjes, dan heb je tot donderdag ontbijt klaarstaan. Ze blijven 4 dagen goed in de koelkast; doe het fruit en de noten er pas 's ochtends op.
---

1. Meng de havervlokken, melk, yoghurt, chiazaad, honing, kaneel en een snufje zout in een kom.
2. Verdeel over 2 potjes of glazen met deksel.
3. Zet minstens 4 uur, maar liefst een nacht, in de koelkast. De havervlokken en het chiazaad nemen het vocht op en worden romig.
4. Roer 's ochtends even door. Is het te dik, voeg dan een scheutje melk toe.
5. Leg het fruit erop en bestrooi met noten of granola.
