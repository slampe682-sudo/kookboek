---
title: Tonijnwrap
emoji: 🐟
categorie: Lunch
tijd: 15
porties: 2
beschrijving: Romige tonijnsalade met kappertjes, rode ui en citroen, met knapperige groenten in een wrap.
ingredienten:
  - { hoeveelheid: 2, eenheid: "", naam: grote tortillawraps }
  - { hoeveelheid: 2, eenheid: blikjes, naam: "tonijn op water (à 145 g), uitgelekt" }
  - { hoeveelheid: 3, eenheid: el, naam: mayonaise }
  - { hoeveelheid: 2, eenheid: el, naam: Griekse yoghurt }
  - { hoeveelheid: 1, eenheid: el, naam: kappertjes }
  - { hoeveelheid: 0.5, eenheid: "", naam: "rode ui, fijngesnipperd" }
  - { hoeveelheid: 0.5, eenheid: "", naam: citroen (sap en rasp) }
  - { hoeveelheid: 1, eenheid: el, naam: "verse dille of bieslook, fijngeknipt" }
  - { hoeveelheid: 1, eenheid: "", naam: "avocado, in plakjes" }
  - { hoeveelheid: 0.25, eenheid: "", naam: "komkommer, in reepjes" }
  - { hoeveelheid: 6, eenheid: "", naam: "cherrytomaatjes, gehalveerd" }
  - { hoeveelheid: 2, eenheid: handjes, naam: little gem of rucola }
  - { hoeveelheid: 75, eenheid: g, naam: maïs uit blik (optioneel) }
  - { naam: zout en zwarte peper }
tip: De yoghurt maakt de salade lichter en frisser dan alleen mayonaise. Lekker met een snufje chilivlokken erbij.
---

1. Doe de uitgelekte tonijn in een kom en prak hem fijn met een vork.
2. Roer de mayonaise, yoghurt, kappertjes, rode ui, dille, het citroensap en de citroenrasp erdoor. Breng op smaak met zout en flink wat zwarte peper. Schep eventueel de maïs erdoor.
3. Verwarm de wraps kort in een droge pan zodat ze soepel worden.
4. Leg een bedje sla op elke wrap en verdeel de tonijnsalade erover. Leg er avocado, komkommer en cherrytomaatjes op.
5. Vouw de onderkant omhoog, sla de zijkanten naar binnen en rol strak op. Snijd schuin doormidden.
