---
title: Franse uiensoep
emoji: 🧅
categorie: Voorgerecht
tijd: 90
porties: 4
beschrijving: Diep gekaramelliseerde uien in bouillon, gegratineerd met stokbrood en gruyère.
ingredienten:
  - { hoeveelheid: 1000, eenheid: g, naam: "gele uien, in dunne halve ringen" }
  - { hoeveelheid: 50, eenheid: g, naam: boter }
  - { hoeveelheid: 1, eenheid: el, naam: olijfolie }
  - { hoeveelheid: 1, eenheid: tl, naam: suiker }
  - { hoeveelheid: 2, eenheid: tenen, naam: "knoflook, fijngehakt" }
  - { hoeveelheid: 1, eenheid: el, naam: bloem }
  - { hoeveelheid: 150, eenheid: ml, naam: droge witte wijn }
  - { hoeveelheid: 1200, eenheid: ml, naam: runderbouillon }
  - { hoeveelheid: 2, eenheid: takjes, naam: verse tijm }
  - { hoeveelheid: 1, eenheid: "", naam: laurierblad }
  - { hoeveelheid: 8, eenheid: plakjes, naam: stokbrood }
  - { hoeveelheid: 150, eenheid: g, naam: "gruyère, geraspt" }
  - { naam: zout en peper }
tip: Neem echt de tijd voor de uien. Het diepe karamelbruin is waar alle smaak vandaan komt.
---

1. Smelt de boter met de olijfolie in een grote pan met dikke bodem. Voeg de uien en een snuf zout toe en laat 10 minuten met het deksel op zacht worden.
2. Haal het deksel eraf, voeg de suiker toe en bak de uien 40–50 minuten op middelhoog tot laag vuur. Roer regelmatig en schraap de bodem los, tot ze diep goudbruin en zoet zijn.
3. Roer de knoflook en bloem erdoor en bak 1 minuut mee.
4. Blus af met de witte wijn en laat even inkoken. Voeg de bouillon, tijm en laurier toe en laat 20 minuten zachtjes koken. Verwijder de kruiden en breng op smaak.
5. Rooster de plakjes stokbrood krokant onder de grill of in de oven.
6. Verdeel de soep over ovenvaste kommen, leg op elke kom 2 plakjes brood en bestrooi royaal met gruyère.
7. Gratineer 3–5 minuten onder een hete grill tot de kaas borrelt en goudbruin is. Serveer direct (pas op, de kommen zijn heet).
