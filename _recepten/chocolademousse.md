ingredienten:
  - { hoeveelheid: 200, eenheid: g, naam: "pure chocolade (70%), in stukjes" }
  - { hoeveelheid: 30, eenheid: g, naam: boter }
  - { hoeveelheid: 4, eenheid: "", naam: "zeer verse eieren, gesplitst" }
  - { hoeveelheid: 40, eenheid: g, naam: suiker }
  - { hoeveelheid: 150, eenheid: ml, naam: slagroom }
  - { naam: snufje zout }
  - { naam: "cacaopoeder, schaafsel of frambozen om te garneren" }
tip: Laat de gesmolten chocolade niet té ver afkoelen, maar ook niet heet zijn als je het eigeel toevoegt. Lauw is perfect. Voor zwangeren of kleine kinderen kun je gepasteuriseerd ei gebruiken.

1. Smelt de chocolade met de boter au bain-marie (een kom boven een pan zacht kokend water). Roer glad en laat 5 minuten afkoelen tot lauw.
2. Roer de eidooiers één voor één door de chocolade.
3. Klop de slagroom lobbig (zacht, nog niet stijf).
4. Klop de eiwitten met het zout schuimig in een schone, vetvrije kom. Voeg de suiker in delen toe en klop tot stijve, glanzende pieken.
5. Spatel eerst een derde van het eiwit door de chocolade om die luchtiger te maken. Spatel daarna voorzichtig de rest van het eiwit en de slagroom erdoor, tot er geen witte strepen meer te zien zijn.
6. Verdeel over glaasjes of kommetjes en laat minstens 3 uur opstijven in de koelkast.
7. Garneer vlak voor het serveren met cacaopoeder, chocoladeschaafsel of verse frambozen.
